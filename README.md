# git-practice-09.02.07

Учебный репозиторий для практики Git и GitHub на C# и .NET.

Цель проекта — освоить:
- создание коммитов;
- работу с ветками;
- слияние изменений и разрешение конфликтов;
- Pull Request и Code Review;
- автоматическое тестирование с помощью GitHub Actions.
